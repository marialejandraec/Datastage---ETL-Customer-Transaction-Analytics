# 🚀 ETL Customer Transaction Analytics

## 📌 Descripción del Proyecto

Proyecto ETL desarrollado en IBM DataStage para consolidar información de clientes, cuentas y transacciones bancarias mediante un flujo de procesamiento complejo orientado a análisis y reporting financiero.

El proceso ETL realiza extracción de datos desde Oracle, validaciones, limpieza de información, eliminación de duplicados, filtros, transformaciones, joins, aggregations y procesamiento mediante Funnel Stage para generar métricas transaccionales e indicadores analíticos.

La solución implementa persistencia intermedia utilizando Dataset Stages para optimizar rendimiento, paralelismo y reutilización de datos durante la ejecución del job.

El objetivo principal es construir una tabla analítica consolidada que permita analizar comportamiento financiero de clientes, volumen transaccional y segmentación de usuarios para dashboards y procesos de inteligencia de negocio.
